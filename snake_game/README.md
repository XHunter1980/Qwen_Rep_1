# 🐍 Змейка (Snake)

Классическая аркадная игра «Змейка» на Python с использованием Pygame.

## Запуск

```bash
pip install -r requirements.txt
python snake.py
```

## Управление

| Клавиши          | Действие                  |
|------------------|---------------------------|
| Стрелки / WASD   | Движение змейки           |
| P                | Пауза / продолжить        |
| R                | Новая игра после проигрыша|
| M                | Включить/выключить звук   |
| ESC              | Выход                     |

## Правила

- Собирай красную еду — змейка растёт, счёт увеличивается.
- Столкновение со стеной, собственным хвостом или **серым камнем** — конец игры.
- На старте на поле 3 камня; каждые 5 очков появляется новый (максимум 15).
- Каждые 5 съеденных кусочков скорость игры растёт.
- **Звуки**: поедание еды, появление камня, смерть и новый рекорд
  синтезируются программно — внешние аудиофайлы не нужны.
- **Рекорд сохраняется между запусками** в файле `highscore.txt`
  (рядом с `snake.py`). При побитии рекорда показывается «НОВЫЙ РЕКОРД!».

## Настройки

Основные параметры вынесены в константы в начале `snake.py`:
размер поля (`GRID_WIDTH`, `GRID_HEIGHT`), размер клетки (`CELL_SIZE`),
начальная и максимальная скорость (`FPS_START`, `FPS_MAX`).
