# 🐍 Змейка (Snake)

Классическая аркадная игра «Змейка» на Python с использованием Pygame.

## Запуск

```bash
pip install -r requirements.txt
python snake.py
```

## Управление

| Клавиши          | Действие                  |
|------------------|---------------------------|
| Стрелки / WASD   | Движение змейки           |
| P                | Пауза / продолжить        |
| R                | Новая игра после проигрыша|
| ESC              | Выход                     |

## Правила

- Собирай красную еду — змейка растёт, счёт увеличивается.
- Столкновение со стеной или с собственным хвостом — конец игры.
- Каждые 5 съеденных кусочков скорость игры растёт.
- Рекорд отображается в правом верхнем углу (в текущей сессии).

## Настройки

Основные параметры вынесены в константы в начале `snake.py`:
размер поля (`GRID_WIDTH`, `GRID_HEIGHT`), размер клетки (`CELL_SIZE`),
начальная и максимальная скорость (`FPS_START`, `FPS_MAX`).
