# ☀️ Солнечная система — интерактивная обучающая демонстрация

Веб-приложение на чистом HTML/CSS/JavaScript (Canvas 2D, без зависимостей),
показывающее Солнце и орбитальное движение всех восьми планет.

## 🚀 Запуск

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
cd solar_system
python3 -m http.server 8090
# затем откройте http://localhost:8090
```

## ✨ Возможности

- **Анимация орбит** — все 8 планет движутся по эллиптическим орбитам;
  периоды пропорциональны реальным (земной год ≈ 20 сек при скорости 1×).
- **Клик по планете** — карточка с фактами: название, диаметр (размер),
  расстояние от Солнца (а.е. и млн км), орбитальный период, число спутников,
  тип планеты и краткое описание.
- **Управление воспроизведением**: кнопки «Пауза / Играть» и «Сброс».
- **Регулирование скорости**: слайдер 0–10× и пресеты 0.5× / 1× / 2× / 5× / 10×.
- **Дополнительно**: переключение орбит и подписей, режим относительных
  реальных размеров планет, tooltip при наведении, поддержка тач-устройств.

## ⌨️ Горячие клавиши

| Клавиша            | Действие                    |
|--------------------|-----------------------------|
| `Пробел`           | Воспроизведение / пауза     |
| `+` / `-`          | Увеличить / уменьшить скорость |
| `Esc`              | Закрыть карточку планету    |
