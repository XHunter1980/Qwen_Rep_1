# ☀️ Солнечная система — интерактивная обучающая демонстрация

Веб-приложение на чистом HTML/CSS/JavaScript (Canvas 2D, без зависимостей),
показывающее Солнце и орбитальное движение всех восьми планет.

## 🚀 Запуск

Просто откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
cd solar_system
python3 -m http.server 8090
# затем откройте http://localhost:8090
```

## ✨ Возможности

- **Анимация орбит** — все 8 планет движутся по эллиптическим орбитам;
  периоды пропорциональны реальным (земной год ≈ 20 сек при скорости 1×).
- **Клик по планете** — карточка с фактами: название, диаметр (размер),
  расстояние от Солнца (а.е. и млн км), орбитальный период, число спутников,
  тип планеты и краткое описание.
- **Управление воспроизведением**: кнопки «Пауза / Играть» и «Сброс».
- **Регулирование скорости**: слайдер 0–10× и пресеты 0.5× / 1× / 2× / 5× / 10×.
- **Дополнительно**: переключение орбит и подписей, режим относительных
  реальных размеров планет, tooltip при наведении, поддержка тач-устройств.

## 🌌 Режим движения по Галактике (спиральные траектории)

Кнопка **«🌌 Галактика»** (или клавиша `G`) включает режим, в котором вся
Солнечная система движется вокруг центра Галактики:

- Солнце летит по галактической орбите (пунктирный эллипс + маркер/стрелка
  «Центр Галактики»), а планеты — по **спирали (циклоиде)**: орбитальное
  вращение плюс перенос вместе с Солнцем. Именно так выглядят реальные
  траектории планет в системе отсчёта Галактики.
- Камера следует за Солнцем; на фоне — спиральные пылевые рукава, ядро
  Галактики и дальние звёзды, движущиеся параллаксом.
- Хвосты-спирали всех планет рисуются «в реальном времени»; у выбранной
  планеты траектория подсвечивается ярким градиентным следом.
- Слайдер **«Вихрь 0.2–5×»** регулирует скорость галактического движения
  (от пологих дуг до плотной пружины), чекбокс **«Траектории-спирали»**
  включает/выключает шлейфы, HUD показывает счётчик витков Солнца.
- Для наглядности масштаб времени сжат: реальный галактический год
  ≈ 230 млн земных лет; в демонстрации один виток Солнца ≈ 4 земных года
  (Земля делает ~4 петли спирали за виток).

## ⌨️ Горячие клавиши

| Клавиша            | Действие                        |
|--------------------|---------------------------------|
| `Пробел`           | Воспроизведение / пауза         |
| `+` / `-`          | Увеличить / уменьшить скорость  |
| `G` (или `П`)      | Режим «Галактика» / классический|
| `Esc`              | Закрыть карточку планеты        |
