## 🚀 Начало работы

### Требования

- [Git](https://git-scm.com/) — система контроля версий
- Доступ к Qwen-AI-агенту

### Установка

```bash
git clone https://github.com/XHunter1980/Qwen_Rep_1.git
cd Qwen_Rep_1
```

## 💻 Использование

1. Клонируйте репозиторий на локальную машину.
2. Создайте новую ветку для работы:
   ```bash
   git checkout -b feature/my-task
   ```
3. Вносите изменения и сохраняйте их с помощью коммитов:
   ```bash
   git add .
   git commit -m "Описание изменений"
   ```
4. Отправьте изменения в удалённый репозиторий:
   ```bash
   git push origin feature/my-task
   ```

## 🤝 Вклад в проект

1. Сделайте форк репозитория.
2. Создайте ветку для новой функциональности: `git checkout -b feature/AmazingFeature`
3. Закоммитьте изменения: `git commit -m 'Добавлена новая функциональность'`
4. Отправьте изменения в ветку: `git push origin feature/AmazingFeature`
5. Откройте Pull Request.
