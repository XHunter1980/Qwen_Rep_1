# ☀️ Солнечная система — интерактивная демонстрация

Веб-приложение на чистом HTML/CSS/JavaScript (Canvas 2D, без зависимостей и сборки):
Солнце, 8 планет на эллиптических орбитах Кеплера, крупнейшие луны, астероиды,
кометы, карликовые планеты, режим «Галактика» и случайные визиты НЛО.

## 🏷 Текущая версия: v7.75

Версия сборки отображается прямо на странице (жёлтый бейдж в панели управления),
в заголовке вкладки браузера и в консоли (`F12`). Если бейджа нет или он показывает
старую версию — вы открыли не тот архив / неполную распаковку.

Краткая история ключевых этапов:
* **v1.0** — базовая демонстрация: Солнце, 8 планет, карточки фактов, пауза/скорость
* **v1.1** — режим «🌌 Галактика»: спиралевидные траектории планет (циклоиды)
* **v1.2** — опциональный слой «🌙 Луны»: крупнейшие естественные спутники
* **v1.3** — бейдж версии сборки на странице
* **v3.x** — хвосты комет (ионный + пылевой, физически мотивированная яркость ~1/r²)
  и слой «👽 Инопланетяне» (НЛО с гравитационным облётом Солнца)
* **v4.5** — «честные разы» от реального времени
* **v7.x** — пояс астероидов, карликовые планеты, зум и панорамирование,
  космическая музыка (Web Audio, файлы не нужны), полноэкранный режим,
  упрощённые орбиты ↔ эллипсы Кеплера, виртуальные часы демо

## 🚀 Запуск

⚠️ **Важно при копировании zip-архива на ПК:** распаковывайте архив ЦЕЛИКОМ
(«Извлечь всё»), а не открывайте `index.html` двойным кликом прямо внутри zip.
Файлы `app.js` и `style.css` должны лежать В ОДНОЙ ПАПКЕ с `index.html` —
иначе браузер не загрузит скрипты и интерфейс (кнопки, луны, спирали) не появится.

После распаковки просто откройте `index.html` в браузере (работает по `file://`,
без сервера), либо запустите локальный сервер:

```bash
python3 -m http.server 8090
# затем откройте http://localhost:8090
```

## ✨ Возможности

- **Анимация орбит** — все 8 планет движутся по эллиптическим орбитам;
  периоды пропорциональны реальным. Переключение режима орбит:
  эллипсы Кеплера ↔ упрощённые круги (кнопка «◯ Упрощённые орбиты», клавиша `O`).
- **Клик по планете** — карточка с фактами: название, диаметр (размер),
  расстояние от Солнца (а.е. и млн км), орбитальный период, число спутников,
  тип планеты и краткое описание. То же работает для лун, астероидов,
  комет, карликовых планет и НЛО.
- **Управление воспроизведением**: кнопки «Пауза / Играть» и «⟲ Сброс».
- **Регулирование скорости**: слайдер и пресеты 0.05× / 0.1× / 1× / 10× / 100× / 1000×
  (старт — 0.05×).
- **Зум и панорамирование**: пресеты «Обзор / 1× / 2× / 4× / 🔍 8×», клавиши `[` `]`,
  стрелки — сдвиг карты, `Home` — центр и обзор 1×.
- **Дополнительно**: переключение орбит и подписей, режим относительных
  реальных размеров планет («🔬 Реальные размеры»), tooltip при наведении,
  сворачивание панели управления, полноэкранный режим, поддержка тач-устройств.

| Клавиша              | Действие                                        |

| `Пробел`             | Воспроизведение / пауза                         |

| `[` / `]`            | Уменьшить / увеличить масштаб                   |
| `Стрелки`            | Панорамирование карты                           |

| `M` (или `Ь`)        | Показать / скрыть луны                          |

| `C` (или `С`)        | Кометы: вкл/выкл                                |
| `D` (или `В`)        | Карликовые планеты: вкл/выкл                    |
| `U` (или `Г`)        | Слой «Инопланетяне»: вкл/выкл                   |

## 🌙 Опциональный слой: крупнейшие луны

Чекбокс **«🌙 Луны»** (по умолчанию включён, клавиша `M`) добавляет крупнейшие
естественные спутники с реальными орбитальными периодами:

- **Земля**: Луна (27.3 сут)
- **Марс**: Фобос (0.32 сут), Деймос (1.26 сут)
- **Юпитер**: галилеевы спутники — Ио, Европа, Ганимед, Каллисто
- **Сатурн**: Титан, Рея, Япет
- **Уран**: Титания, Оберон
- **Нептун**: Тритон (5.88 сут, ретроградное обращение — учтено направлением)

Луны обращаются вокруг своих планет во всех режимах (включая «Галактику»),
их орбиты рисуются пунктиром; клик по луне открывает карточку со всеми
данными: название, диаметр, расстояние до планеты-хозяина, период обращения.
Масштаб лунных орбит условно увеличен для наглядности.

## 🪨 Астероиды, кометы и карликовые планеты

- **«🪨 Астероиды» (B)** — Главный пояс астероидов плюс Церера, Веста, Паллада, Гигея.
- **«☄️ Кометы» (C)** — медленные длиннопериодические кометы Гейла–Боппа и NEOWISE
  на вытянутых эллиптических орбитах. Хвосты физически мотивированы: яркость
  ~1/r² (сублимация льдов), два хвоста — прямой голубой ионный (от Солнца)
  и широкий жёлтый пылевой (слегка изогнутый, отстаёт от движения).
- **«🪐 Карликовые планеты» (D)** — Плутон, Эрида, Макемаке, Гаумеа (пояс Койпера)
  и Церера в главном поясе.

## 👽 Инопланетяне

Случайные визиты НЛО: примерно раз в 25–60 секунд реального времени в систему
влетает корабль одной из пяти «цивилизаций», делает гравитационный облёт вокруг
Солнца и улетает прочь по касательной. Во время визита показывается уведомление.

- Чекбокс **«👽 Инопланетяне»** — включить/выключить слой (горячая клавиша `U`).
- Кнопка **«🛸 Позвать гостя»** — вызвать визит немедленно (для демонстрации).
- Клик по кораблю открывает карточку «контакта» (название, раса, траектория).

## 🎵 Космическая музыка

Фоновая музыка генерируется прямо в браузере через Web Audio API —
никаких аудиофайлов в архиве нет. Кнопка «🎵 Космическая музыка» или клавиша `P`.

## 🛠 Работа с репозиторием

### Требования

- [Git](https://git-scm.com/) — система контроля версий
- Любой современный браузер (Chrome, Firefox, Edge, Safari)

### Установка и запуск

```bash
git clone https://github.com/XHunter1980/Qwen_Rep_1.git
cd Qwen_Rep_1
# открыть index.html в браузере
```

### Разработка

1. Создайте новую ветку для работы:
   ```bash
   git checkout -b feature/my-task
   ```
2. Вносите изменения и сохраняйте их коммитами:
   ```bash
   git add .
   git commit -m "Описание изменений"
   ```
3. Отправьте изменения в удалённый репозиторий:
   ```bash
   git push origin feature/my-task
   ```

## 🤝 Вклад в проект
