# SolarSystem

Репозиторий для демонстратора Солнечной Системы

## 📋 Описание

Этот репозиторий предназначен для работы с Qwen-AI-агентом над демонстратором Солнечной Системы: хранения кода, конфигураций и артефактов, создаваемых в ходе взаимодействия с агентом.

## 📁 Структура проекта

```
Qwen_Rep_1/
├── README.md            # Этот файл — описание проекта
├── .gitignore           # Список игнорируемых Git файлов и директорий
└── solar_system/        # ☀️ Интерактивная демонстрация Солнечной системы
    ├── index.html       #   разметка: canvas, панель управления, инфо-карточка
    ├── style.css        #   оформление интерфейса
    ├── app.js           #   анимация орбит, луны, галактический режим (спирали)
    └── README.md        #   подробная инструкция по запуску и возможностям
```

## 🌌 Демонстрация Солнечной системы

Интерактивная educational-демо на чистом HTML/CSS/JS (Canvas 2D, без зависимостей):
Солнце + 8 планет, клик по планете/луне — карточка с фактами, пауза/скорость,
13 крупнейших лун и режим «Галактика» со спиральными траекториями.

**Как запустить:** распакуйте архив ЦЕЛИКОМ (не открывайте index.html прямо из zip),
затем откройте `solar_system/index.html` в браузере — все файлы (`app.js`, `style.css`)
должны лежать в одной папке с `index.html`. Подробности — в `solar_system/README.md`.

## 💻 Использование

1. Клонируйте репозиторий на локальную машину.
2. Создайте новую ветку для работы:
   ```bash
   git checkout -b feature/my-task
   ```
3. Вносите изменения и сохраняйте их с помощью коммитов:
   ```bash
   git add .
   git commit -m "Описание изменений"
   ```
4. Отправьте изменения в удалённый репозиторий:
   ```bash
   git push origin feature/my-task
   ```

## 🤝 Вклад в проект
